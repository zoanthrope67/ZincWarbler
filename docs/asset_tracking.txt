ZINC WARBLER - ASSET TRACKING
=============================

Placeholder assets made by Claude. Each should be replaced by a human-made asset
and then removed from this list. Placeholder files and nodes start with
"placeholder" / "Placeholder" so they are easy to search for.

Files
-----
src/gfx/placeholder/placeholder_theme.tres
    UI theme used by every screen (Project Settings > GUI > Theme > Custom).
    Only sets the default font size (40) with Godot's built-in font.
    Replace with the final UI theme and font.

src/gfx/placeholder/placeholder_wall_library.tres
    MeshLibrary used by the arena GridMap. One item, "PlaceholderWall":
    a grey-blue 4 x 4 x 4 m box with a matching box collision shape.
    Replace with a MeshLibrary made from the final wall models (keep box
    collision shapes for performance).

Nodes inside scenes
-------------------
src/scn/bootstrap.tscn -> PlaceholderLoading
    "Loading..." text label. The spec asks for a "Loading..." graphic.

src/scn/main_menu.tscn -> Center/Layout/PlaceholderTitleSplash
    "ZINC WARBLER" text label. The spec asks for a title splash image;
    replace with a TextureRect showing the final splash.

src/scn/game/player.tscn -> Model/PlaceholderBody, Model/PlaceholderNose
    Blue 2 m sphere with a white box on its front (+Z) to show facing.
    Replace both with the player model as children of Model (front facing +Z).
src/scn/game/player.tscn -> AnimationPlayer, animations "dash" and "RESET"
    Placeholder dash animation: stretches PlaceholderBody along its facing.
    Keep the animation names; the code plays "dash" during a dash and
    "RESET" when it ends.

src/scn/game/player_bullet.tscn -> PlaceholderMesh
    Yellow unshaded 0.5 m sphere.

src/scn/game/flag.tscn -> PlaceholderPole, PlaceholderBanner
    Grey pole with a green box banner.

src/scn/game/enemy_bullet.tscn -> PlaceholderMesh
    Purple unshaded 0.5 m sphere.

src/scn/game/tank.tscn -> Model/PlaceholderBody, Model/PlaceholderBarrel
    Orange box with a dark cylinder barrel pointing forward (+Z).

src/scn/game/angry_greg.tscn -> Model/PlaceholderBody, Model/PlaceholderNose,
                                Model/PlaceholderBrowLeft, Model/PlaceholderBrowRight
    Dark red 4 m sphere with a box nose and two slanted "angry" brow boxes.

Enemy models: put replacements under each enemy's Model node, front facing +Z.
The fade-in works with StandardMaterial3D/ORMMaterial3D materials; meshes using
a ShaderMaterial will appear without fading.

src/scn/game/arena.tscn -> PlaceholderLight, PlaceholderEnvironment
    One directional light without shadows. The environment's settings are a
    placeholder; the sky image it uses (src/gfx/sky/autumn_field_puresky_1k.hdr)
    was added by the designer, not made by Claude.
src/scn/game/arena.tscn -> PlaceholderFloor (PlaneMesh, ShaderMaterial)
src/gfx/placeholder/placeholder_noise_colour_floor.gdshader
    The floor: a 1000 x 1000 m unshaded plane at y = 0 with a grid whose lines
    shift between two colours in slowly drifting Perlin noise patches.
src/scn/game/arena.tscn -> Walls (GridMap cell layout), spawn points and flags
    A test layout (about 80 x 60 m) for prototyping. Expected to be
    redesigned by the game designer. The outer ring of walls was removed for
    the BorderStorm; only the inner walls remain.

src/scn/game/border_storm.tscn -> StormOverlay (PlaneMesh, ShaderMaterial)
src/gfx/shaders/border_storm.gdshader
    The look of the BorderStorm: everything outside the circle in greyscale with
    TV static (white noise) over it, and a hard edge at the radius. Replace the
    look as needed; the circle and alpha uniforms are set from
    scripts/game/border_storm.gd.

src/scn/ui/health_pip.tscn -> PlaceholderFrame, PlaceholderFill, AnimationPlayer
    Dark square with a red fill. The "lose" animation flashes the fill white,
    grows it, then shrinks and fades it out; "empty" leaves only the frame.
    Keep the animation names "full", "lose" and "empty".

src/scn/ui/hud.tscn -> TopBar labels, YouDied (Dim, Banner, ContinueHint), AnimationPlayer
    Plain text score/time, a dark overlay and a red "YOU DIED" label that types
    in ("you_died") then pulses ("you_died_loop"). Keep those animation names.

src/scn/ui/pause_menu.tscn -> MenuScreen (Dim, Title, Menu, HoldBar, Warning)
    Dark overlay with a "PAUSED" text title, text menu items, Godot's default
    ProgressBar as the hold bar, and an orange text warning.
src/scn/ui/pause_menu.tscn -> CountdownScreen/PlaceholderCountdownNumber, AnimationPlayer
    Large yellow outlined "3", "2", "1" text. The "countdown_tick" animation
    pops it in (scale and fade) once per number. The spec asks for animated
    sprites; keep the animation name, the code plays "countdown_tick" for each number.

src/scn/name_entry.tscn, src/scn/game_over.tscn
    Text-only layouts using the placeholder theme.
