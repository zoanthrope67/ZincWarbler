# Overview

The player should be able to pause the game. Pausing should bring up a menu.

# New Controls

Pause Button - Escape on keyboard, Start on controller.

They should not be able to rebind the Pause Button and Escape/Start should not be a valid option to be bound.

# Gameplay changes

When the player presses pause, all gameplay should be paused and a new menu should be displayed. This menu will contain the following options:

 * Resume
 * Restart
 * Exit

When the player selects Resume, then the menu should disappear and gameplay should resume after 3 seconds. There should be animated sprites and an FX Signal (Countdown) emitted for 3 seconds, 2 seconds and 1 second. The signal's argument should be the current number. The player cannot pause again during the countdown.

When the player selects Restart, then the game should be reset to the beginning as if a new game was started. This should not allow the player to save their high score.

When the player selects Exit, then the game should be ended and go back to the main menu. This should not allow the player to save their high score.

To avoid accidental button presses ending a game session, the player needs to hold the Confirm button to Restart or Exit. A bar should fill up while they hold the button; this should take 0.5 seconds to fill. Resume is instant. If the player has a score that would go into the hi-score table then they should be warned about this by a text message that appears when the user is over this item in the menu.

The user is not able to pause while the player is dead.

# New FX Signals

 * Countdown(int)
 * Pause_Menu_Entered
 * Pause_Resume
 * Pause_Restart
 * Pause_Exit
